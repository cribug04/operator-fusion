# 本地验证与待办

本次在 Jax 的 Mac 本地运行，使用隔离 Python 环境（Python 3.14 / NumPy 2.5.4）。仅验证 CPU 参考与测试基础设施；没有连接或运行 NPU。

## 已完成

- 修复 bf16 对比工具总是返回成功的问题：0=通过，1=数值不达标，2=数据或参数错误。
- 拒绝空文件、奇数字节文件、NaN/Inf、大小不匹配、不合法裁剪和显式形状不一致。
- 使用三个显式判据：`exact` 为逐位相同；默认 `resize` 为相同率 ≥99.9% 且最大近似 ULP ≤2；`conv-cpu` 为余弦 ≥0.9999 且最大近似 ULP ≤4。有限且逐位一致的数据直接通过。
- 阈值沿用仓库原有操作手册，不是新获得的官方精度要求；ULP 指标仍是参考值附近的近似 ULP。
- 上板脚本检查 OS/RT 状态、输出存在性与大小、三次运行一致性；数值对比失败停止。拒绝复用已存在的 OUT，避免把旧输出混入新结果。
- 更新打包脚本打印的比较命令，区分快慢路严格对比和 CPU 容差对比。
