# 题二 · NPU Top-K 选择

给 NPU 一列分数，它返回最高的 16 个分数以及它们在原列表中的位置。
从 0 开始编号，同分时先取编号小的候选。每轮先找剩余的最高分，再从
同分候选中找最小编号，把它划掉后继续。输入和比较全程使用 FP32。

当前演示接口接收 256 个小端 FP32，占 1024 字节。输出先存 16 个小端 FP32
分数，再存 16 个小端有符号 32 位编号，共 128 字节。支持有限的正规 FP32
和正负零。零按数值相等处理。NaN、无穷和次正规数不在当前验收范围。
这是本地演示接口。官方样例、精度规格、输入尺寸和 K 的范围待拿到后核对。

源码位于 calBLAS 的 examples/topk。进入该目录执行以下命令可生成 CalVX。

```bash
cargo build --locked --lib --target dopamine-unknown-none-cvx
```

把产出的 topk_demo.cvxo 复制为新目录下的 step.cvxo，放入空文件
param_blk0.bin，然后运行 `docc calbin from-calvx <目录> --no-params --network topk -o cal`。
用 `python3 verify.py generate cases` 生成测试输入。

在比赛设备上进入已打包的目录，运行 `bash run_board.sh 0`，将 0 替换为设备编号。
脚本逐个运行测试，并与 CPU 完整排序的答案比较分数和编号。六组输入覆盖打乱顺序、
全负数、并列、全零、最小有限 FP32 和只能靠 FP32 精度区分的接近分数。
该算子是确定性选择，输入相同就应给出相同结果。

本地已通过 NPU 编译、CalBin 静态解析和 CPU 参考及校验器自测。真机结果和执行速度待测。
正确性通过后，以相同输入、K 和 FP32 精度对比官方基线。记录预热次数、样本数、稳态中位数
和 P95。裸字节 CLI 的整条命令耗时包含部署与输入输出。
